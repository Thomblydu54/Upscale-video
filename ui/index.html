L'IA regarde chaque image (lumière, couleurs, teinte, lumières vives…) et applique la finition qui lui va le mieux. Une même vidéo peut en utiliser une seule, deux ou les six : tout dépend des images.

  • Doré couchers de soleil, lumière chaude
  • Glacé neige, ciel, mer, nuit bleue
  • Glow anime néons, lampes, lumières dans la nuit
  • Cinéma scènes sombres, feutrées ou ternes
  • Éclatant scènes de jour aux couleurs normales
  • Netteté seule noir et blanc, images déjà très vives

Sans clignotement : la finition change en fondu dans un même plan, et nettement à chaque changement de plan. L'aperçu IA montre la finition choisie pour l'image affichée.

Configurer ma Freebox · une seule fois
              
  1. Dans Freebox OS (mafreebox.freebox.fr), relevez votre IPv4 publique et la plage de ports disponibles. Choisissez un port dans cette plage (ou un port libre si vous avez une IPv4 full-stack).
    2. 
                
  2. Réservez une IP locale fixe à ce PC dans le DHCP de la Freebox. 
    3. 
                
  3. Dans Paramètres de la Freebox → Mode avancé → Gestion des ports, redirigez ce seul port TCP vers l'IP de ce PC, avec le même port de destination.
    4. 
                
  4. Autorisez l'application sur votre réseau privé dans le pare-feu Windows. Ne désactivez pas le pare-feu et n'utilisez pas la DMZ.
    5. 
                
  5. Saisissez https://votre-IPv4-publique:port ci-dessus. Aucun domaine ni certificat payant n'est nécessaire : le code d'appairage contient l'empreinte du certificat privé.

              
Le PC principal doit rester allumé pendant la liaison. Le PC de calcul n'a besoin que de connexions sortantes. Le test final se fait depuis l'autre réseau, pas depuis le Wi-Fi de cette Freebox.
